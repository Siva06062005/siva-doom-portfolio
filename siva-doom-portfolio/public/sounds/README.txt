CUSTOM AUDIO FILES DIRECTORY
=============================

Place your custom .mp3 or .wav sound effect files in this folder:

  • hover.mp3         (Played when hovering over buttons, cards, & brand logos)
  • click.mp3         (Played when clicking buttons, links, & cards)
  • stark.mp3         (Played when switching to STARK MODE)
  • doom.mp3          (Played when switching to DOOM MODE)
  • keypress.mp3      (Played when typing in the CLI terminal)
  • transmission.mp3  (Played when sending a message on the Contact page)
  • warning.mp3       (Played on CLI error or privilege warnings)

Note: If an MP3 file is not found in this folder, the website automatically synthesizes real-time futuristic Web Audio API HUD sounds instead!
